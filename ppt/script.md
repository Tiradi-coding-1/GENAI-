## Vibe Coding 心得（2 分鐘）

### 優勢：
1. 效率提升：幾分鐘完成原本需要幾天的工作
2. 降低門檻：不需要精通 Python
3. 技能轉型：從寫程式轉向指揮 AI

### 挑戰：
1. 字體顯示問題
2. 資料完整性（部分股票抓不到）
3. API 限流需要處理

##可能被問的問題

**Q: 為什麼選這 15 檔股票？**
A: 透過 Google Search 研究台灣半導體與 AI 產業鏈，篩選具有代表性且在 Yahoo Finance 可查詢的上市股票。

**Q: yfinance 資料準確嗎？**
A: yfinance 是 Yahoo Finance 的 API，資料來源正規，但部分股票可能因市場因素無法取得。

**Q: Vibe Coding 適合什麼情境？**
A: 適合需要快速原型、开高低收數據處理的專案，但不適合需要深度領域知識的系統級開發。
